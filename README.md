# Excel-to-PDF-Invoice-Generator-using-Python
This project automatically generates **PDF invoices** from an Excel file using Python. It is useful for freelancers, small businesses, or automation lovers who want to generate bills/invoices without manual work.
# What This Project Does

1. Reads data from Excel file

2. Generates invoice for each row

3. Automatically names and saves PDF invoices

4. Useful for bulk billing or client orders
# Project Files Explained:
# invoice_generator.py
This is the core script of the project. It reads customer order data from the Excel file (sample_invoice_data.xlsx) and automatically generates a PDF invoice for each entry (row).
Output Example:

invoice_INV001.pdf

invoice_INV002.pdf

...and so on.
# sample_invoice_data.xlsx
Sample Excel Data File
This Excel file contains mock invoice data with columns.
